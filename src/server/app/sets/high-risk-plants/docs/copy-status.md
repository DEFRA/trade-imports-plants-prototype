# Copy that has not been through a content review

Every page's copy below is provisional until a content designer reviews it.
Welsh files headed `MACHINE-DRAFT Welsh` are machine translations that a
translator has not reviewed; do not ship them to users without Welsh Language
Standards sign-off. The dashboard's Welsh is also a machine draft awaiting that
sign-off.
