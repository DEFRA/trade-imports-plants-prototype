# Design gaps: routing

Things the design asks for that the GOV.UK toolbox in this prototype cannot
build yet. Each row travels with the hand-off brief.

| Page | What the design wants                                                                       | Closest option built                                                                                                                                                        | Why                                                                                                                                                                                                                                                             | Frame |
| ---- | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| find | A conversational interface where the trader says what they are importing in their own words | One question per page, each a type-ahead (`appAccessibleAutocomplete`), with "What you have told us" as a `govukSummaryList` under the question                             | A chat-style page that updates as the trader types needs new client JavaScript, which belongs to the real service.                                                                                                                                              | None  |
| find | Search that understands everyday words such as "cow" or "Christmas tree"                    | The type-ahead matches the UK Trade Tariff's own wording and the commodity code                                                                                             | The type-ahead only matches text inside each option; synonyms need a search service or new client JavaScript.                                                                                                                                                   | None  |
| find | Route the trader to the right notification for plants, live animals and germinal products   | A front door in this release that starts the high-risk plants notification, and a placeholder overview page for CHED-PP, CHED-A and CHED-P showing the answers carried over | Needs a real service: the real front door belongs to ins-frontend (the Import Notification Service frontend), not plants-frontend, and the other notifications are not in this prototype, so a placeholder stores nothing and does not appear on the dashboard. | None  |
| find | Commodity codes for plants, live animals and germinal products                              | 227 codes copied from the UK Trade Tariff API on 13 October 2026 into `services/commodity-routing/tariff.js`                                                                | Needs a real service: no reference-data service in the prototype supplies commodity codes, so the list is a snapshot and will go out of date.                                                                                                                   | None  |
| find | Routing rules that say which notification each commodity needs                              | Draft rules in `services/commodity-routing/index.js`, written from the plant health risk categories and what the high-risk plants notification covers                       | Needs a real service: the rules have not been checked by policy and no service owns them.                                                                                                                                                                       | None  |
